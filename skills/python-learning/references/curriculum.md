# 章节路径与知识图谱

章节对应 tutorial.md 同编号小节。基础讲解与必备能力优先；13、14 为应用拓展，08 先达到能阅读即可，进阶面向对象不作首课门槛。

|编号|主题|知识内容|前置|可观察目标|
|---|---|---|---|---|
|01|程序全貌|输入输出、执行顺序、缩进|无|说清数据如何流动|
|02|变量与类型|变量、类型转换、None|01|分清数字与字符串|
|03|表达式与字符串|运算、真假、索引切片、格式化|02|预测表达式结果|
|04|容器|列表、元组、字典、集合、复制|02,03|读写多条记录|
|05|条件|分支、边界、逻辑组合|03|正确表达互斥规则|
|06|循环|遍历、累计、range、推导式|04,05|批量处理且终止正确|
|07|函数|参数、返回值、作用域、默认值|02,05,06|拆解任务并返回结果|
|08|对象与类|属性、方法、实例、self|04,07|读懂点号与简单类|
|09|模块与环境|import、包、venv、pip、入口|01,07|区分安装与导入|
|10|文件与格式|路径、with、编码、CSV、JSON|04,09|读写并核对数据|
|11|异常与调试|Traceback、try、raise、输入校验|05,07|用证据定位错误|
|12|验证|assert、边界、口径、回归|07,11|先写预期再检验|
|13|表格与图表|pandas、汇总、图表|04,06,09,10|按场景拓展|
|14|API 与 AI|请求响应、JSON、凭据、失败|09,10,11|理解外部调用边界|
|15|AI 协作|需求、样例、迭代、核对|07,12|验收 AI 生成代码|
|16|综合实践|校验、汇总、输出、验证|06,07,10,11,12|交付成绩报告|
|17|地图与复习|自测、前置关系、后续路径|01|找到知识缺口|

推荐首学顺序：01→02→03→04→05→06→07→09→10→11→12→16；08 按需读懂，13～15 根据任务选学；17 用于总览。学生可以点名任意章节，缺少前置时只补当前必要部分，不强迫从头学。

进阶入口：字符串→正则；函数→装饰器；循环→迭代器；文件→数据库；API→异步；模块→打包；类→继承。先掌握前置再拓展。
