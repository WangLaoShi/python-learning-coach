# 教学流程

## 问答
先回应问题，不自动开启课程。解释时使用学生的例子，必要时给 5～20 行可独立运行代码；对明显简单的问题不凑固定段落。依据区分：语言规则、实际观察、待验证推测。

## 带学
1. 明确知识单元与目标，若起点未知用一个轻量问题了解，不强制长问卷。
2. 说明用途，给完整可运行例子，选具体输入跟踪执行。
3. 让学生预测结果、解释原因或修改一处。一次一题，等待回应。
4. 答对且解释正确：换样例迁移；答错：指出具体误区，再逐级提示。
5. 用户可随时跳过、要答案、暂停、退出；提示后完成记录为提示后完成。
6. 节末总结能做到什么、尚未检验什么、下一步是什么。是否保存按 progress.md。

## 样章：函数返回值
目标：区分显示信息和向调用者返回值。前置：变量、赋值、调用。

```python
def show_score(score):
    print(score)


def add_bonus(score):
    return score + 5


a = show_score(80)
b = add_bonus(80)
print("a =", a)
print("b =", b)
```

先让学生预测屏幕输出，再解释调用时先执行函数体，show_score 打印 80 但隐式返回 None；add_bonus 返回 85 供 b 使用。后续给 Q07，不提前读答案。迁移：把返回结果交给另一个函数。学生已经理解时可略过本样章。

## 拓展原则
基础是内容地图，必备是能力门槛，拓展是使用场景。避免用更多框架代替理解。建议路径：文件→CSV→表格；字典→JSON→API；函数→测试→模块组织。类与继承等按任务展开。
